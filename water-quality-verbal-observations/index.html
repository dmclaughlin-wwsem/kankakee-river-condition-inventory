Water context
Filters the plot, map, statistics, and displayed value range to readings within the stated range of concern.
Data-quality view
Most Representative Data: includes all otherwise valid measurements except dissolved oxygen readings of 0.1 mg/L or less, which are treated as likely measurement artifacts and hidden when this option is selected. The underlying values remain in the source spreadsheet. This option does not remove observations based on conductivity, inflow context, or other parameter values.
Output
Export downloads the records currently shown after applying all active filters. Print uses the same current dashboard view.

Interpretation Notes

Nitrate: raw, uncorrected Eureka multiprobe estimates.
Value slider: filters the plot, map, and statistics within the selected parameter range. Map color: remains continuous within the values currently shown; intermediate colors do not indicate condition thresholds.
Observation text: omitted from chart and map pop-ups to keep them concise. The original narrative observations remain available in the source spreadsheet.
Chart pop-ups: include the river segment name so the displayed segment remains identifiable when “All segments” is selected and the value slider narrows the visible records.
Marker shape: circle = likely mainstem; diamond = potential inflow influence.
Export Current View: downloads a CSV containing only records visible after all active segment, context, data-quality, range-of-concern, and value-range filters. The export begins with a short description of the selected view. Print: uses a two-page landscape layout. Page 1 keeps the dashboard controls, statistics, and notes together. Page 2 places the displayed time chart and map side-by-side, with their legends and explanatory information. The displayed-view status documents the active filters.
